### Projects

- **[gpu-bench](https://github.com/imalachowsk-creator/gpu-bench)** — honest CPU vs GPU benchmarking
  (Python, PyTorch, CUDA). Measured on an NVIDIA T4: where the GPU starts to win, what moving data
  costs, how much memory a model needs — with built-in checks that reject results which are fast
  only because they are wrong.
